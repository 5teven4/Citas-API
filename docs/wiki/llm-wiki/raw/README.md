# Fuentes raw

**Propósito:** conservar el inventario inmutable de fuentes curadas que nutren
la wiki.

Las especificaciones iniciales continúan en sus rutas canónicas del workspace
para evitar copias divergentes. `source-registry.md` fija su origen, tamaño y
hash SHA-256 al momento de la ingesta inicial. Para una fuente nueva, el agente
debe registrarla antes de sintetizarla y no debe modificarla después.

Las fuentes raw no son páginas wiki: no contienen inferencias, decisiones ni
resúmenes generados por IA.
